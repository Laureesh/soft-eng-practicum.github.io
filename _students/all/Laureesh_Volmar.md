## My Role in the Project

Satisfeed is a nonprofit working to address food insecurity in Gwinnett County. Its dashboard helps staff explore distribution data and community resources through interactive maps, charts, and summaries.

**Sponsor:** Satisfeed and Georgia Gwinnett College (NSF-HSI)  
**Team Size:** Solo
**Duration:** 12 weeks – Fall 2026

As a software development intern, I help improve and extend Satisfeed’s existing application. My work includes updating React and Next.js components, improving map interactions and navigation, assisting with data modeling, and documenting changes and setup instructions.

I’m also developing access controls for members, admins, and superadmins, along with a Manage Admins page for viewing, searching, and removing admin access. Other contributions include API request validation, clearer error handling, and Docker-based development setup. Admin management and API security improvements are still in progress.

I use Git and GitHub to manage my changes, review team contributions, and resolve merge conflicts.
